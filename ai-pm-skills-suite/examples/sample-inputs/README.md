# Sample Inputs

Use this folder for realistic dry-run inputs.

## Suggested files
- `prd-example-notes.md`: raw notes that should become a PRD
- `discovery-example.md`: vague idea + user pain points
- `prioritization-example.md`: initiative list with rough value/effort assumptions
- `evaluation-example.md`: experiment outcome / model result notes
- `meeting-example.md`: meeting transcript or bullet notes
- `kpi-example.md`: metric snapshot or anomaly brief
- `retro-example.md`: launch issue summary and timeline

## Authoring rules
- Keep inputs realistic and slightly messy.
- Include enough ambiguity that the skill must structure the output.
- Mark any invented business context clearly as sample-only.
