# PRD Example Notes

- 主题：报告编辑器智能审核助手
- 目标：帮助工程师在提交报告前发现数据冲突、规范缺失、表达风险
- 用户：环评/可研工程师、项目负责人
- 现状问题：
  - 报告编辑器里经常到最后才发现章节缺字段
  - 不同章节数据口径不一致，人工校验很慢
  - 工程师习惯用外部 AI 工具，但内容容易脱离项目上下文
- 希望能力：
  - 基于当前报告全文或选中段落做问题检测
  - 给出风险解释、修改建议、是否需要补数据
  - 支持按章节查看问题清单
- 版本要求：
  - 首发只做问题识别 + 风险提示 + 跳转定位
  - 第二版再做自动改写建议
- 研发限制：
  - 首发不做全文异步批处理
  - 先基于当前项目内容，不跨项目检索
- 需要在 PRD 中体现：
  - 页面逻辑
  - 数据来源优先级
  - 边界与异常情况处理
  - 埋点需求
