# User Scenario Patterns (Sanitized)

## 用户场景写法
- 不直接写“用户想要某功能”，而是写“用户在某流程节点要完成某任务”
- 场景描述至少覆盖：触发条件、目标动作、成功结果
- 对 AI 类需求，额外说明当前人工成本或认知负担

## 常见场景模板
### 模板 1：流程内即时辅助
- 触发：用户在编辑、填写、核查某页面时遇到阻碍
- 目标：获得解释、建议或校验支持
- 结果：减少返工、降低切换成本、提升完成效率

### 模板 2：多模块信息联动
- 触发：用户问题依赖多个业务模块的数据
- 目标：一次获得统一回答或统一建议
- 结果：避免手工跨页面核对

### 模板 3：信息缺失 / 无法回答
- 触发：用户提问超出当前上下文或数据未准备好
- 目标：系统明确说明缺失原因而不编造
- 结果：用户知道下一步该补什么
