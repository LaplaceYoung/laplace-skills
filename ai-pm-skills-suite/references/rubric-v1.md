# Rubric v1

## Dimensions
1. Problem framing accuracy — 25
2. Actionability of output — 25
3. Contract / format compliance — 20
4. Risk awareness / assumption quality — 15
5. Bilingual consistency — 15

## Scoring guidance
- 90-100: directly usable with only cosmetic edits
- 85-89: usable with minor edits
- 70-84: partially useful, needs meaningful revision
- <70: not promotion-ready

## Deduction rules
- Critical hallucination: automatic fail for the run
- Missing required section: -10 each
- Unsupported assumption presented as fact: -10 each
- CN/EN field mismatch: -5 each
