# 中文专项 Rubric（每项 0-5）

1. 人话自然度
- 是否像真实中文表达，而非翻译腔。

2. 信息清晰度
- 主线是否明确，是否能快速读懂。

3. 语气贴合度
- 与场景匹配（聊天/发帖/学术/长文）。

4. 句式健康度
- 是否避免同构重复、定义句连发、空洞判断。

5. 事实保真度
- 是否保持原始信息不走样。

## 专项扣分
- 定义句/判断句过密（学术模式）：-1 到 -3
- 绝对语气无证据：-1 到 -2
- 官样套话堆砌：-1 到 -3
- 结尾口号化：-1

## 通过阈值
- 推荐 >= 20/25，且事实保真度 >= 4。
- 学术模式下：定义句与绝对语气违规项 <= 1。
