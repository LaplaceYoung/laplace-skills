# Humanvoice Rubric (0-5 each)

1. Naturalness
- Reads like a real person, not a template.

2. Clarity
- Main point is obvious, structure is easy to follow.

3. Specificity
- Uses concrete details instead of vague filler.

4. Tone Fit
- Tone matches audience and scene.

5. Information Fidelity
- Keeps source facts and intent intact.

## Penalties
- Mechanical phrase penalty: -1 to -3
- Empty-summary ending penalty: -1
- Jargon overload penalty: -1 to -2

## Pass threshold
- Recommended pass: >= 20/25 and no fidelity failure.
