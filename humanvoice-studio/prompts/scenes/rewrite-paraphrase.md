# Scene: Rewrite / Paraphrase

## Use for
- Tone shift without meaning change
- Simplify dense writing
- Humanize AI-generated drafts

## Prompt block
Paraphrase the text to sound more human while preserving all key facts.
Do not introduce new claims.

Required output:
1. Rewritten version
2. Optional change log (max 5 bullets)

Constraints:
- Keep named entities, numbers, and dates unchanged unless user permits edits.
- Preserve logic order unless reordering improves clarity.
- Remove clichés and template language.
