# 中文核心规则

## 总目标
- 让中文输出“像人写的”，而不是“翻译腔/模板腔”。
- 在自然表达和信息准确之间保持平衡。

## 句子节奏
- 以短中句为主，长句只用于承接复杂逻辑。
- 每段至少有一句可独立成意的短句。
- 避免连续三句同构句式。

## 词汇选择
- 优先常用词，不用生硬书面套语。
- 能具体就不抽象，能动词就不名词化。
- 避免空泛增强词："非常重要"、"显著提升"（无证据时）。

## 中文自然度约束
- 避免英译痕迹："在...方面进行"、"值得注意的是"、"综上所述"（默认禁用）。
- 避免口号句堆砌，优先事实+动作+结果。
- 段落首句直接入题，不铺垫空话。
- 减少“先否定再肯定”的对照句（不是A而是B / A而不是B），优先直接正向陈述。
- 不用“总结一下/一句话说/简而言之”等总结标签句。

## 事实保真
- 数字、时间、实体名优先保持原样。
- 原文无结论时，不补绝对性判断。

## De-AI Pass（中文二次处理）
在输出前执行一次专门去模板检查：
1. 删除开场客套和模板过渡语。
2. 打散机械对称结构：避免连续三段同长度、同句式。
3. 强制句长波动：短句与中长句交替。
4. 把抽象名词链改写为“动作+对象+结果”。
5. 结尾收束到具体观察或问题，不喊口号。
