# Anti-patterns

Avoid these patterns unless the user explicitly asks for them:

- "As an AI language model..."
- "In today's fast-paced world..."
- "It is worth noting that..."
- "Overall / In conclusion / To sum up" as default endings
- Bullet spam where prose is better
- Repetitive hedge chains: "might possibly perhaps"
- Hollow intensifiers: "very very", "extremely" without concrete support

Self-check before final output:
- Is any sentence saying nothing new?
- Is the tone mismatched with audience?
- Is there at least one concrete detail anchoring each key point?
