# Style Rules

## Universal rules
- Start with the point, not a generic preface.
- Keep each paragraph focused on one idea.
- Favor verbs over noun-heavy constructions.
- Replace abstract fillers with observable details.
- Remove duplicate statements.

## Sentence-level rules
- Average sentence length target: 12-24 words.
- At least one short sentence every paragraph.
- Avoid stacked subordinate clauses unless needed for precision.

## Word-level rules
- Prefer simple vocabulary unless domain terms are required.
- Keep jargon only when it carries necessary meaning.
- Avoid buzzword clusters.

## Structure rules
- Use explicit structure in long outputs: hook -> point -> evidence -> implication.
- End with a concrete close, not a generic summary line.
