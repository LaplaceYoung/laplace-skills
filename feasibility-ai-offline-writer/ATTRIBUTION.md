# Attribution

This directory packages locally recovered prompt and outline artifacts from the FeasibilityAI desktop application into an offline reusable skill.

## Packaged scope in this repository

The `feasibility-ai-offline-writer` pack currently includes transformed or reorganized material such as:

- `SKILL.md`
- `agents/openai.yaml`
- `assets/prompts.json`
- `assets/outlines.json`
- `references/*.md`
- `scripts/*.py`

## Packaging note

In `Laplace Skills`, these materials are repackaged for offline prompt lookup, outline selection, and workflow reuse. This pack is intentionally model-agnostic and does not include any live-service authentication, API replay, or secret-handling workflow.

No independent upstream license is asserted here beyond the rights held by the original materials and any local transformations applied in this repository.
