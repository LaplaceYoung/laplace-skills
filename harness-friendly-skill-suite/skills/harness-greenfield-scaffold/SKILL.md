# Greenfield Scaffold

## Outputs
- entry docs
- governance docs
- templates
- skill/plugin placeholders
- naming policy
- adaptation-plan template

## Process
1. create obvious entrypoint docs first
2. add governance and protected-area rules early
3. scaffold only the minimum useful folders and templates
4. make outputs standardized so future agents know where to look
5. include evaluator criteria and reporting artifacts from the start

## Evaluator criteria
- a fresh agent can understand the repo layout quickly
- docs reveal where safe changes belong
- reports/templates exist before future runs need them

## Rules
- optimize for discoverability
- keep layout lightweight
- avoid speculative complexity
- prefer standard names and artifact paths
