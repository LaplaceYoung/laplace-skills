# Design Brand System Reference Index

Use this file before opening any brand reference.

## Selection Shortlist

- Minimal monochrome product systems: `apple`, `vercel`, `notion`, `raycast`, `superhuman`
- Dark developer-tool systems: `linear.app`, `vercel`, `cursor`, `claude`, `clickhouse`, `warp`
- Premium consumer and hardware: `apple`, `tesla`, `bmw`, `ferrari`, `lamborghini`, `nvidia`
- Playful or expressive SaaS: `airbnb`, `figma`, `framer`, `miro`, `mintlify`, `lovable`
- Fintech and trust-heavy product UI: `stripe`, `coinbase`, `wise`, `revolut`, `kraken`
- AI product and model-brand interfaces: `claude`, `cohere`, `minimax`, `mistral.ai`, `together.ai`, `x.ai`, `ollama`
