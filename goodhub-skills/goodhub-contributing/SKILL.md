# goodhub-contributing

Write contribution guidance matched to the repo size.

## Include
- how to set up locally
- how to run tests or checks
- branch and PR expectations
- commit style if enforced
- documentation expectations
- how to report bugs or discuss ideas

## Keep it proportional
- Small repo: keep it short.
- Community repo: add review flow, triage notes, and expectations.

## Deliverables
Produce one of:
- full `CONTRIBUTING.md`
- lightweight contribution section
- contribution checklist
