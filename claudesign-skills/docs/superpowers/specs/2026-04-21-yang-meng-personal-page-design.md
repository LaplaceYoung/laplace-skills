# 杨萌个人宣传页设计规格

**日期**：2026-04-21  
**目标**：用 Claude Design 风格能力验证已安装的插件 / skills / MCP 流程，产出一个适合模态跃迁公司的个人宣传页 Demo。  
**约束**：

- 减少卡片使用
- 采用强叙事、强排版、强层级的单页结构
- 案例与成就使用明确标注的模拟数据
- 交付形态为可预览 HTML artifact

## 方向备选

### 方案 A：品牌海报式单屏宣传

- 优点：冲击力强，适合分享截图
- 代价：案例和履历承载密度偏低

### 方案 B：编辑化个人长页

- 优点：最适合减少卡片，同时容纳案例、成就、方法论和 CTA
- 代价：对排版节奏要求高

### 方案 C：演讲 deck 式滚动页

- 优点：适配导出与演示
- 代价：浏览器内的信息连续性偏弱

## 选定方向

选择 **方案 B：编辑化个人长页**。

## 信息架构

1. Hero：姓名、职位、公司定位、核心一句话
2. Signature Strip：三条能力标签与方法论摘要
3. About：个人简介与公司业务语境
4. Case Studies：三段模拟案例，采用左右交错编排
5. Achievements：时间轴 + 行内数字成就
6. Working Style：合作方式与交付节奏
7. CTA：联系行动区

## 视觉原则

- 主气质：东方编辑感 + 商业增长叙事
- 主色：暖纸色、墨蓝、铜金
- 结构：大标题、细分割线、留白层次、带状分区
- 组件：优先使用段落、规则线、时间轴、数据带、双栏，不依赖均质卡片网格

## 验证标准

1. 首屏 3 秒内能看懂“杨萌是谁、做什么、服务谁”
2. 案例与成就区在无卡片堆叠下仍具备清晰层级
3. 页面在本地预览、done gate、verifier 下通过
4. 模拟数据标识清楚
